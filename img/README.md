# Hero image

`hero.jpg` is the diamondback photograph used as the hero background on the landing
page. It is referenced by `.hero-art` in `index.html`, layered over a generated
canyon gradient so the page still reads correctly if the file is absent.

Drop the image in as `hero.jpg`. Guidance: landscape, at least 2000px wide, subject
right-of-centre so the headline sits over the dark left side. The wash over it is
already heavy, so a dark original works better than a bright one.
